## Поток данных (что добавляется к дню 2)

```
камера → perception → classifier   (день 2, работает)
              │
              ▼ /item/classification
        controller_node (НОВОЕ):
          - мягкий пуск ленты при старте (decisions.md 2026-07-11)
          - B → ничего (лента довозит до конца рабочей секции)
          - C → fire_time (tracking.py) → толкатель C (+Y… существующий)
          - D → fire_time → толкатель D (НОВОЕ, зеркальный, −Y-сторона? нет:
            зона D на −Y ⇒ толкатель D стоит на +Y и толкает в −Y)
```

Управление механизмами переводится с `ign topic` на ROS-мосты
(`ros_gz_bridge`: Float64 ↔ ignition.msgs.Double), время — сим-время Gazebo
(`/clock` мост + `use_sim_time`), иначе dead-reckoning разъезжается со
stamp'ами кадров.

## Пункты (по одному, коммит + пуш после каждого)

1. **int: мосты управления и часов** — в `sim/bridge.yaml`: `/clock`
   (GZ→ROS), `/conveyor/cmd_vel`, `/pusher_c/cmd`, `/pusher_d/cmd`
   (ROS→GZ, Float64↔Double). Проверка: `ros2 topic pub` двигает ленту/толкатель.
2. **sim: толкатель D** — зеркальный существующему (тот переименовывается в
   `pusher_c`): +Y-сторона, толкает в −Y к зоне D; `smoke_pusher.sh` гоняет оба.
   Проверка: Тарелка уходит с ленты на D-сторону.
3. **int: controller_node** — подписка `/item/classification`; мягкий пуск
   ленты при старте; C/D → `fire_time()` (упреждение с латентностью хода
   лопатки), таймер выстрела→возврата. Чистая логика — pytest на Windows,
   node-тест — WSL/CI.
4. **int: сквозной прогон** — `scripts/run_skeleton.sh`: мир + спавн по seed →
   launch → чекер исходов (B: x≥3.5 на ленте; C/D: товар на патче зоны).
   Прогон Короб 300 → B и Тарелка → D; cycle time в `experiments.md`;
   тег `v0.1-skeleton`.
5. **sim: удержание круглых** — эксперимент по решению 2026-07-11: неглубокий
   жёлоб/V-лоток ПРОТИВ низких бортов с окном. Критерии: Шлем стабилен;
   perception не ломается (тест на новом кадре); толкатель добивает Тарелку.
   Итог — в `decisions.md`.
6. **docs: архитектура + видео** — черновик раздела «архитектура контура»
   (соответствует реальным нодам), видео/GIF прогона из кадров камеры,
   итоги дня в `PLAN-7DAYS`-стиле.

## Риски

- Тайминг толкателя: латентность хода лопатки ≈ 0.25 с при 1 м/с ленты — 250 мм
  упреждения; если дребезг велик, снизить скорость ленты нельзя (константа) —
  увеличить ход/скорость лопатки.
- `use_sim_time` на всех нодах обязателен: смешение wall/sim времени — тихий
  провал dead-reckoning (Карпаты №6: assert на возраст stamp'а в контроллере).
- Прекат ленты (−3.2) перед эпизодом — обязателен для запаса хода 6.4 м.
