# Финальная сдача 2 августа — пошаговый runbook

Актуализировано по инструкции организаторов от 02.08. Дедлайн — **2 августа,
23:59 МСК**. После него нельзя загружать, изменять или удалять файлы.

## 1. Что обязательно

- видеодемонстрация решения — в персональную папку команды в Nextcloud;
- текстовый отчёт — в GitHub или Nextcloud;
- презентация — в GitHub или Nextcloud;
- код, README, зависимости, конфигурации и инструкции запуска — в командный GitHub.

Для задачи 3 тяжёлые модели, CAD, файлы симуляции и другие бинарные материалы
кладутся в Nextcloud. Архивы ZIP/RAR загружать **нельзя**: только исходные файлы
и распакованные папки. Лимит папки — 100 ГБ, одного файла — 20 ГБ.

## 2. Проверить GitHub

В сдачу идёт `main` командного репозитория
`hackathonsrus/ozone-tech_ii_v_massy_883`. Оба ремоута должны указывать на один
коммит. Перед push CI остаётся ручным (`workflow_dispatch`), чтобы финальная
редактура не расходовала Actions-минуты.

В GitHub обязательны:

- `README.md` — точка входа и команды запуска;
- `docs/report/final_report.md` — итоговый отчёт;
- `docs/report/slides/deck-c-ozon.html` — исходник слайдов для редактирования и
  сборки записанной презентации;
- исходный код, тесты, Docker/ROS/Gazebo-конфигурации.

## 3. Собрать распакованную папку Nextcloud

Если финальные логи `runs/` уже получены:

```bash
python scripts/make_nextcloud_bundle.py
```

Если логи ещё у участника, выполнявшего прогоны:

```bash
python scripts/make_nextcloud_bundle.py --without-runs
```

Обе команды создают **папку** `build/II_v_massy_Task3/` и `MANIFEST.md`. Вторая команда
честно записывает отсутствие `05-run-artifacts`; эту папку можно дозагрузить
отдельно до дедлайна. Не превращать результат в архив.

Не загружать `ozon_stream.mp4`, `demo_reel.mp4`, `build/`, `install/`, `log/`.

## 4. Загрузить в Nextcloud

1. В личном кабинете открыть «Решения» → ссылку «Хранилище Nextcloud».
2. Ввести пароль из письма организаторов; пароль не хранить в репозитории.
3. Нажать «+ Новый» → «Загрузить папки» и выбрать готовую папку
   `build/II_v_massy_Task3/`. Она загрузится распакованной под понятным именем.
4. Загрузить в `04-presentation` файл `II_v_massy_pitch.mp4` — текущую
   записанную презентацию продолжительностью 5:17. Если позднее появится PDF,
   добавить его в тот же раздел.
5. Проверить, что видеодемонстрация и презентация открываются и скачиваются.
6. Создать общедоступные ссылки на конкретные файлы презентации и видео и
   проверить их в приватном окне браузера.

## 5. Проверить README и комплект

Ссылка на папку Nextcloud и ссылка на видеодемонстрацию уже указаны в
`README.md`. После загрузки презентации выполнить:

```bash
python scripts/check_submission.py
```

Результат должен быть `SUBMISSION PREFLIGHT: PASS`. Затем отдельно проверить
обе ссылки в приватном окне браузера: локальная проверка не может подтвердить
содержимое защищённой паролем папки Nextcloud.

## 6. Заполнить поле «Решение» на платформе

Поле ограничено 1500 символами. В нём обязательны краткое описание и ссылки на:

- презентацию;
- видеодемонстрацию.

Ссылки на GitHub и отчёт полезно добавить дополнительно. После проверки нажать
«Отправить». Решение можно обновлять до дедлайна: после замены презентации нужно
обновить ссылку и снова отправить форму.

## 7. Финальная проверка

- [ ] оба GitHub-репозитория указывают на один коммит;
- [ ] `check_submission.py` печатает PASS;
- [ ] в Nextcloud лежат распакованные папки, а не архив;
- [ ] видеодемонстрация открывается и скачивается;
- [ ] презентация открывается и скачивается;
- [ ] ссылки работают в приватном окне;
- [ ] поле «Решение» содержит обе обязательные ссылки и отправлено до 23:59 МСК.
