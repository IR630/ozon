# Runbook пробной сдачи (задача H2/H6 ledger PLAN-WEEK5)

> Механический чек-лист живого человека для пробной и финальной сдачи. Всё, что
> агент может проверить сам, вынесено в `scripts/check_submission.py` (repo-preflight)
> и `scripts/check_clean_deploy.sh` (деплой). Здесь — порядок шагов вокруг них и
> человеко-блоки, которые скрипты закрыть не могут. Внутренние дедлайны
> (`PLAN-WEEK5.md`): **пробная сдача 29.07**, готовность 01.08, сдача **02.08**.
>
> Пробная сдача 29.07 — это репетиция МЕХАНИКИ загрузки (формат, лимиты размера,
> ссылки), а не дедлайн сборки: пакет должен быть собран ЦЕЛИКОМ к 26.07, чтобы
> пробная ловила баги упаковки, а не открывала недособранный комплект.

## 0. Предусловия
- Ветки с правками ядра (`cv/round-body-to-d`, `fix/robustness-audit`) — НЕ в `main`
  до Gazebo-gate; в сдачу идёт `main`. Если gate пройден и слито — пересобрать образ.
- Пуш только в `origin` (github.com/IR630/ozon), никогда в `true` (см. правило сессии).

## 1. Repo-preflight — `python3 scripts/check_submission.py`
Проверяет наличие обязательных артефактов, отсутствие плейсхолдеров, отсутствие
случайных крупных бинарников, **целостность локальных ссылок** и HTTPS-видео-ссылку.
- Ожидаемо СЕЙЧАС: `BLOCKED` ровно на одном — `PLACEHOLDER: README.md: <ссылка на
  облако...>`. Это единственный человеко-блок (шаг 2). Всё остальное должно быть чисто.
- Любой другой пункт (`MISSING`/`LARGE`/`BROKEN_LINK`/`CLOUD_LINK`) — чинить до сдачи.

## 2. Видео в облако + ссылка в README (единственный человеко-блок preflight)
1. Смонтировать ролик по `video_script.md` (задача H2).
2. Залить в облако организаторов; получить **HTTPS**-ссылку.
3. Вписать её в `README.md` строка 48 (`**Видеодемонстрация:** <ссылка>`), заменив плейсхолдер.
4. Повторить `check_submission.py` → должно стать **`PASS`**.

## 3. Чистый деплой — `bash scripts/check_clean_deploy.sh` (задача H5)
Доказывает, что решение разворачивается так, как его получат организаторы: чистый
`git archive HEAD` (без кэшей/`runs/`/`install/`) → сборка pinned docker-образа с
нуля → headless CPU e2e внутри образа (`ci_e2e.sh`: colcon build `ros_msgs` →
`WORLD=cell_diverter` → `run_skeleton box_300 B`, камера→классификатор→шибер).
- Нужен **docker**. Тестируется КОММИТ, не рабочее дерево — коммить перед прогоном.
- **Прогнать на ЧУЖОЙ машине** (вторая физическая среда, совет №2): локальный PASS
  уже есть; чужой прогон ловит зашитые пути/зависимости. Ожидание — **дважды упасть**,
  прежде чем поверить, что деплой чист.
- Ограничение сейчас: у интегратора WSL2 сломан (`HCS_E_HYPERV_NOT_INSTALLED`, нет
  Docker) — нужна машина, где docker работает.

## 4. Карта критериев → артефакт — `docs/report/criteria_coverage.md`
Пройти построчно все 7 разделов (130 баллов): у каждого ✅ — рабочая ссылка на файл;
каждый ⛔ (за человеком) — закрыт этим runbook'ом (видео H2, деплой H5, пробная H6,
репетиция H7). 🟡 (выбор варианта слайдов) — команда фиксирует финальный.

## 5. Что в репо, что в облако (`GIT.md`)
- **В репо:** код, `docs/report/*`, README-навигация, SDF-миры, `docker/`, тесты,
  один money-shot клип (`hero_stream_mixed_cd.mp4`), CAD STEP/STL/чертёж.
- **В облако организаторов (ссылки собраны в README):** полная видеодемонстрация,
  крупные бинарники/веса/датасеты, тяжёлые CAD-исходники, объёмные логи `runs/`.

## 6. Пробная загрузка на платформу (29.07)
Прогнать реальную загрузку комплекта на платформу организаторов как репетицию:
- Проверить формат/структуру пакета, лимиты размера загрузки, доступность облачных
  ссылок из-под чужого аккаунта, что README открывается как оглавление.
- Зафиксировать любые баги механики (не помещается, ссылка приватная, битый
  архив) — это и есть цель пробной, до реального дедлайна.

## 7. После пробной → финальная сдача (02.08)
- Починить всё, что вскрыла пробная. Повторить `check_submission.py` (PASS) и
  `check_clean_deploy.sh` (PASS) на финальном коммите.
- Резерв 31.07–01.08: репетиция защиты 7 мин + Q&A (`qa_prep.md`), форс-мажор,
  ничего нового.
