## Посегментно

### 1 · 0:00–0:20 · Интро
- **Экран:** титул (трек 3, команда) → короткий проброс money-shot (3–4 с без звука).
- **Закадр:** «Участок предсортировки: камера над лентой видит товар, классифицирует
  и физически раскладывает по трём зонам. Весь контур замкнут в симуляции и
  воспроизводится одной командой.»

### 2 · 0:20–1:00 · Задача и контур
- **Экран:** схема участка A→B/C/D + блок-схема `perception→classifier→controller→шибер`
  (из `architecture.md`).
- **Титр:** `B — в сортировщик · C — негабарит · D — круг в сечении (доупаковка)`.
- **Закадр:** «Ошибка сортировки — это затор и ручной труд. Наш контур — единый ПАК,
  а не два компонента: результат классификации напрямую становится управляющим
  сигналом механизма.»

### 3 · 1:00–2:00 · Классификация и пограничные случаи
- **Экран:** depth-кадр с наложенной маской, id и подписью `dims / K` (overlay); рядом
  блок правил.
- **Титр:** `габариты 10³…450×320×320 мм · круг в сечении K=r_впис/R_опис > 0.8 ·
  приоритет габаритов над формой`.
- **Закадр:** «Классифицируем по геометрии depth, не по цвету и не по названию.
  Пограничные случаи — доказательство глубины: Цилиндр K≈0.75 — не круг, это ловушка;
  Шлем K=0.78 — впритык под порогом; Ручка 9 мм и Пуфик 489 мм — габарит важнее формы.»

### 4 · 2:00–3:30 · ДЕМО (money shot) ★ ядро
- **Экран:** `hero_stream_mixed_cd.mp4` целиком — 5 товаров подряд в C/D на финальном
  диверторе. Оверлеем по ходу: маршрут каждого (bottle→D, plate→D, box→C, pouf→C, pen→C).
- **Закадр (поверх, синхронно):** «Камера увидела → классификатор набрал уверенность
  по кадрам → контроллер по упреждению сформировал стенку лопасти ДО прихода товара →
  лента свела товар со скоростью ленты на склиз → зона. И механизм вернулся.»

### 5 · 3:30–4:05 · Цилиндр → B (K-правило вживую)
- **Экран:** `hero_diverter_cylinder_B.mp4` — Цилиндр проходит нетронутым мимо лопастей в B.
- **Титр:** `K≈0.75 < 0.8 → B: имя круглое, сечение — нет`.
- **Закадр:** «Вот почему классификация по сечению, а не по названию: у Цилиндра
  четыре продольных стяжки делают сечение некруглым — он идёт в основной сортировщик.»

### 6 · 4:05–5:05 · Исполнительная часть и бережность
- **Экран:** крупный план дивертора (замедление на формировании стенки и возврате);

- **Титр:** `шибер, не толкатель · ≥1.3× (точечно 3.0×) мягче по пиковому ускорению ·
