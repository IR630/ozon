# Расчёт привода лопасти-дивёртера (компенсация «идеального привода»)

> Закрывает строку 3 слайда `docs/defense/physics_oneslide.md` и единственную
> несущую аналитическую дыру, названную вердиктом совета
> (`docs/defense/council_physics.md`). Цифровая модель приводит лопасть идеальным
> позиционным приводом: мгновенным, без люфта, момента, ресурса. Здесь показано,
> что требуемый момент **конечен и мал**, и серийный привод с запасом закрывает
> оба режима — разгон стенки и удержание под потоком.
>
> Геометрия и массы — из `sim/worlds/cell_diverter.sdf` (лопасть-линк `blade`).
> Тайминги — `src/constants.py` / `stream_plan.py` через `calc_vs_sim.md`.

## Данные лопасти (из SDF, сознательно консервативные)

| Параметр | Значение | Источник |
|---|---:|---|
| Масса лопасти `m_b` | 5.0 кг | `<inertial><mass>` (стальная плита; реальная алюминиевая легче → момент ниже) |
| Инерция вокруг COM `I_c` | 0.1 кг·м² | `<inertia>` SDF |
| Плечо COM от оси `d` | 0.40 м | `<pose>-0.40 0 0>` короба относительно оси |
| Длина рабочей грани | 0.80 м | `<box><size>0.80 …` |
| Ось вращения | вертикальная (Z) | `<axis><xyz>0 0 ±1` |
| Угол постановки стенки `θ` | 0.785 рад (45°) | комментарий SDF; предел сустава 0.95 рад |
| Время формирования стенки `t` | 0.5 с (`FIRE_LEAD_S`) | стенка готова ДО входа товара |
| Худший товар | Box 400, `m = 3 кг`, `v = 1.0 м/с` | `physics_assumptions.md` |

Момент инерции относительно **оси** (не COM), по теореме Штейнера:

```
I_ось = I_c + m_b·d² = 0.1 + 5.0·0.40² = 0.90 кг·м²
```

Ось вертикальна ⇒ **сила тяжести не создаёт момента** вокруг неё: разгон чисто
инерционный, удержание угла в покое — нулевой гравитационный момент (в отличие от
подъёмного звена, где вес держал бы ток).

## Режим 1 — разгон: сформировать стенку за `FIRE_LEAD_S`

Повернуть на `θ = 0.785 рад` за `t = 0.5 с` из покоя в покой. Профиль
минимального пикового момента — bang-bang (разгон первую половину, торможение
вторую):

```
α = 4θ / t² = 4·0.785 / 0.25 = 12.6 рад/с²
ω_пик = 2θ / t = 3.14 рад/с
τ_разгон = I_ось·α = 0.90·12.6 = 11.3 Н·м
```

## Режим 2 — удержание: товар давит на стенку под потоком ленты

Лента анизотропна (`mu∥ = 1.0`), поэтому максимальная продольная сила, которой она
толкает товар в стенку:

```
F_лента = mu∥·m·g = 1.0·3·9.81 = 29.4 Н  (по +X)
```

Товар не останавливается, а скользит вдоль грани (`mu_грань = 0.2`) и уводится
к кромке. Стенка реагирует нормальную составляющую этой силы на грани 45°:

```
N = F_лента·sin 45° = 29.4·0.707 = 20.8 Н
```

Момент на оси зависит от точки контакта вдоль 0.80 м грани:

| Точка контакта | Плечо `r` | `τ_удержание = N·r` |
|---|---:|---:|
| середина грани (типично) | 0.40 м | 8.3 Н·м |
| у кромки (худший случай) | 0.80 м | 16.6 Н·м |

## Сводка и подбор серийного привода

```
τ_пик = max(τ_разгон, τ_удержание) = max(11.3, 16.6) ≈ 17 Н·м
τ_спец = 2·τ_пик ≈ 34 Н·м  (запас ×2 на люфт, износ, разброс трения)
```

**Класс привода:** серводвигатель ~400 Вт с червячным или планетарным редуктором
20:1 даёт 20–40 Н·м продолжительного момента при `ω_пик = 3.14 рад/с` (30 об/мин на
выходе) — стандартная, недорогая, широко доступная комплектация. **Червячная пара
самотормозящаяся:** удерживает угол постановки на протяжении `HOLD_S = 2.5 с` без
удерживающего тока, что снимает тепловой режим удержания.

Проверка по скорости: выход 3.14 рад/с = 30 об/мин — глубоко в номинале любого
такого привода, момент разгона (11.3 Н·м) ниже момента удержания, поэтому
продолжительный режим определяется удержанием, а пиковый (кратковременный) — с
большим запасом.

## Что этот расчёт НЕ покрывает (честная граница)

- Момент удержания взят как **квазистатическая** нормальная реакция; переходный
  пик первого касания зависит от жёсткости контакта и позы товара и аналитически
  не выводится (как и бережность в `calc_vs_sim.md`). Он ограничен сверху тем же
  пиком приземления, что уже измерен в симуляции, и режется склизом
  (`chute_angle.md`).
- Не рассчитаны: прочность вала/крепления на усталость, люфт редуктора и его
  влияние на точность угла, тормозной путь при E-stop, ресурс подшипника, тепло
  привода на длинном горизонте. Это — предмет инженерного проекта привода, не
  цифровой модели; здесь показана только **достижимость момента серийным узлом**.
- Масса лопасти 5 кг — значение SDF (консервативно завышено для стальной плиты).
  Реальная алюминиевая грань 0.8×0.3 м толщиной 3 мм весит ~0.2 кг, что снижает
  `I_ось` и `τ_разгон` примерно на порядок; расчёт намеренно оставлен на тяжёлой
  цифре, чтобы вывод «серийный привод с запасом» держался в худшую сторону.
