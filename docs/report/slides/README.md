# Презентации защиты — запуск

Три варианта деки по 9 слайдов, содержание одинаковое, отличается оформление:

| Файл | Стиль |
|---|---|
| `deck-a-swiss-modern.html` | швейцарская типографика, светлый |
| `deck-b-cobalt-grid.html` | кобальтовая сетка, тёмный |
| `deck-c-depth-gauge.html` | глубина/шкалы, тёмный |

## Запуск

Из корня репозитория, PowerShell:

```powershell
python -m http.server 8000 --directory docs/report
```

Открыть `http://localhost:8000/slides/deck-a-swiss-modern.html`.

Остановить — `Ctrl+C` в том же окне.

**Корень сервера — обязательно `docs/report`, не `slides`.** Клип на слайде 6
подключён как `../video/hero_stream_mixed_cd.mp4`, то есть лежит уровнем выше
деки. `http.server` не отдаёт ничего выше своего корня: если поднять сервер
внутри `slides/`, HTML откроется, а видео вернёт 404 и слайд 6 покажет
серую заглушку.

Из корня репо тоже работает, просто адрес длиннее:
`python -m http.server 8000` → `http://localhost:8000/docs/report/slides/deck-a-swiss-modern.html`.

**Открывать двойным кликом (`file://`) нельзя** — часть браузеров под этой схемой
блокирует загрузку соседних файлов, и видео опять не появится. Только через сервер.

## Управление

| Клавиша | Действие |
|---|---|
| `→` / `PageDown` | следующий слайд |
| `←` / `PageUp` | предыдущий |
| `Home` / `End` | первый / последний |
| `Пробел` | пуск и пауза клипа (слайд 6) |
| `E` (или `У`) | режим правки текста прямо на слайде |
| `Ctrl+S` | сохранить правки |

Колесо мыши тоже листает.

## Видео

Слайд 6 использует `docs/report/video/hero_stream_mixed_cd.mp4` — единственный
клип, лежащий в репозитории (721 КБ, H.264/yuv420p, 800×450, 36 с). Остальные
записи прогонов в гит не кладём, они в облаке организаторов (см. `.gitignore`).

Клип стартует автоматически при переходе на слайд, звука нет, крутится в цикле.
Пока первый кадр не декодирован, на его месте стоит подписанная заглушка — так
отсутствие файла видно заранее, а не чёрным прямоугольником во время защиты.

## Если слайд 6 пустой

1. Проверить, что файл на месте: `ls docs/report/video/hero_stream_mixed_cd.mp4`.
2. Проверить корень сервера — самая частая причина (см. выше).
3. Открыть консоль браузера (`F12`) и посмотреть, не 404 ли запрос к `.mp4`.

Отдельно стоит знать про уже исправленный баг: класс `ready`, открывающий клип,
раньше вешался только по событию `loadeddata`, а слушатель регистрировался в конце
`<body>` — локальный файл успевал декодироваться раньше, событие уходило в пустоту,
и видео играло невидимым под заглушкой. Чем быстрее отдача, тем стабильнее ломалось.
Сейчас перед подпиской проверяется `readyState`. Если правите этот код — не
возвращайте «чистую» подписку на событие.

## Перед защитой

Прогнать деку целиком на той машине и в том браузере, с которых будете
показывать: разрешение, шрифты и автоплей видео зависят от машины.
