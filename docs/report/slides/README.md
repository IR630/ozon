# Презентации защиты — запуск

**Дека одна: `deck-c-ozon.html`, 12 слайдов.** Три альтернативных оформления
(swiss-modern, cobalt-grid, depth-gauge) удалены 02.08. Они несли по одному видео
вместо пяти, застряли на девяти слайдах и **не синхронизировались по содержанию**
— то есть открыть на защите не тот файл значило показать жюри устаревшие числа.
Один файл нельзя открыть по ошибке.

Главное отличие от исходной деки: **основные цвета несут саму плоскость.**
Фон слайда — насыщенное поле «синий → фиолетовый → маджента», как в рекламных
макетах Ozon, а текст идёт белым поверх него. Тонкие цветные акценты по
почти-чёрному — ровно противоположный подход, от него отказались.

Раскладка палитры на смысл (цвет здесь не украшение, а значение):

| Цвет | Роль в деке |
|---|---|
| Ozon blue `#005BFF` | сам фон, структура, хром, полоса прогресса |
| Ozon magenta `#F91155` | масса в правом нижнем углу поля; ближнее поле, зона D |
| Aqua blue `#27D1EB` | среднее поле: камера и её измерения |
| Morning blue `#00A2FF` | холодная поддержка, нумерация звеньев |
| Wreath green `#06CA9A` | зона B — товар идёт как есть |
| Yellow star `#FBE671` | зона C — вне габаритов |
| Night sky `#270097` | фиолетовая середина градиента |

**В типографике — только два главных цвета: белый текст и сплошная маджента
на акцентном слове. Градиента в буквах нет и не должно быть.** Любой переход
между двумя тонами обязан пройти через всё, что лежит между ними: жёлтый в
мадженту тащит через оранжевый и салатовый, и подбором точек это не лечится.
Очевидный брендовый переход синий→маджента здесь ещё хуже — синий конец
садится на синее поле и буквы растворяются.

Зелёный, жёлтый и аква остаются только как ФУНКЦИОНАЛЬНЫЕ сигналы (зона B,
зона C, камера) и никогда не появляются в заголовках. Это осознанный размен:
жюри читает таблицу вердиктов с одного взгляда, без легенды.

Три вещи в вёрстке держат читаемость на таком фоне — их лучше не трогать:

1. **Скрим** поверх поля (`.field::after`) гасит поверхность на ступень. Именно
   он позволяет фону быть настолько насыщенным: без него белый текст на 25 px
   начинает плыть.
2. **Стеклянные панели** (`--panel`, `--panel-solid`) под плотным содержимым —
   карточки правил, плитки цифр, таблица пограничных случаев, точки маршрута.
   Таблица тянется во всю ширину, её правая колонка приходится ровно на
   маджентовый угол, а маджентовая «D» на мадженте — это не вердикт.
3. **Приглушённый текст — белый с альфой, не серый.** Серый на синем мутнеет
   и иерархия рассыпается.

Маджентовая масса поля намеренно стоит в правом нижнем углу: на всех девяти
слайдах это самая пустая область.

## Запуск

Из корня репозитория, PowerShell:

```powershell
python -m http.server 8000 --directory docs/report
```

Открыть `http://localhost:8000/slides/deck-c-ozon.html`.

Остановить — `Ctrl+C` в том же окне.

**Корень сервера — обязательно `docs/report`, не `slides`.** Клип на слайде 6
подключён как `../video/hero_stream_mixed_cd.mp4`, то есть лежит уровнем выше
деки. `http.server` не отдаёт ничего выше своего корня: если поднять сервер
внутри `slides/`, HTML откроется, а видео вернёт 404 и слайд 6 покажет
серую заглушку.

Из корня репо тоже работает, просто адрес длиннее:
`python -m http.server 8000` → `http://localhost:8000/docs/report/slides/deck-c-ozon.html`.

**Открывать двойным кликом (`file://`) нельзя** — часть браузеров под этой схемой
блокирует загрузку соседних файлов, и видео опять не появится. Только через сервер.

## Управление

| Клавиша | Действие |
|---|---|
| `→` / `PageDown` | следующий слайд |
| `←` / `PageUp` | предыдущий |
| `Home` / `End` | первый / последний |
| `Пробел` | пуск и пауза клипа (слайд 6) |
| `E` (или `У`) | режим правки текста прямо на слайде |
| `Ctrl+S` | сохранить правки |

Колесо мыши тоже листает.

## Видео

Слайд 6 использует `docs/report/video/hero_stream_mixed_cd.mp4` — единственный
клип, лежащий в репозитории (721 КБ, H.264/yuv420p, 800×450, 36 с). Остальные
записи прогонов в гит не кладём, они в облаке организаторов (см. `.gitignore`).

Клип стартует автоматически при переходе на слайд, звука нет, крутится в цикле.
Пока первый кадр не декодирован, на его месте стоит подписанная заглушка — так
отсутствие файла видно заранее, а не чёрным прямоугольником во время защиты.

## Если слайд 6 пустой

1. Проверить, что файл на месте: `ls docs/report/video/hero_stream_mixed_cd.mp4`.
2. Проверить корень сервера — самая частая причина (см. выше).
3. Открыть консоль браузера (`F12`) и посмотреть, не 404 ли запрос к `.mp4`.

Отдельно стоит знать про уже исправленный баг: класс `ready`, открывающий клип,
раньше вешался только по событию `loadeddata`, а слушатель регистрировался в конце
`<body>` — локальный файл успевал декодироваться раньше, событие уходило в пустоту,
и видео играло невидимым под заглушкой. Чем быстрее отдача, тем стабильнее ломалось.
Сейчас перед подпиской проверяется `readyState`. Если правите этот код — не
возвращайте «чистую» подписку на событие.
