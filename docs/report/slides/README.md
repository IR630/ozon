# Исходник презентации

`deck-c-ozon.html` содержит 12 слайдов защиты. Это редактируемый исходник,
который используется для локального просмотра и сборки записанной презентации.
Основной презентационный файл сдачи —
[записанная презентация в Nextcloud](https://disk.ozon-robozon.ru/s/xeToaJw95awTb5C)
продолжительностью 5:17. Путь к файлу:
`II_v_massy_Task3/04-presentation/II_v_massy_pitch.mp4`.

## Локальный просмотр

Из корня репозитория выполнить:

```bash
python -m http.server 8000 --directory docs/report
```

Затем открыть в браузере:

```text
http://localhost:8000/slides/deck-c-ozon.html
```

Сервер должен запускаться с корнем `docs/report`, потому что слайд 8 загружает
видеофайлы из соседней папки `docs/report/video`. При открытии HTML двойным
щелчком через `file://` браузер может заблокировать эти файлы.

Остановить сервер можно сочетанием `Ctrl+C` в терминале.

## Управление

| Клавиша | Действие |
|---|---|
| `→` / `PageDown` | следующий слайд |
| `←` / `PageUp` | предыдущий слайд |
| `Home` / `End` | первый / последний слайд |
| `Пробел` | запуск или пауза видео на слайде 8 |
| `E` или `У` | режим редактирования текста |
| `Ctrl+S` | сохранить изменения |

## Используемые видео

Слайд 8 использует пять H.264-файлов из `docs/report/video`: основной поток
`hero_stream_mixed_cd.mp4` и четыре коротких примера маршрутов B, C и D. Все эти
файлы находятся в репозитории и проверяются командой
`python scripts/check_submission.py`.

Полная шестиминутная видеодемонстрация `census_reel.mp4` является отдельным
материалом сдачи и размещена в Nextcloud.

## Проверка после изменений

```bash
python scripts/check_deck_layout.py
python scripts/check_submission.py
```

Первая команда проверяет, что текст помещается на всех слайдах. Вторая проверяет
наличие файлов, на которые ссылается презентация и остальная документация.
