# H4 · CAD-эскиз ячейки: съезд <10 см и reject-лоток

Инженерный эскиз к задаче H4 (страховка обоснования УГТ «исполнение 4»):
наклонный съезд товара в клетку вместо свободного падения 0,40 м и reject-лоток
для штатных аномалий вместо остановки линии. Это **вид сбоку** — дополнение к
виду сверху `docs/report/img/cell_layout.svg`.

## Файлы

| Файл | Что это |
|---|---|
| `geom.py` | Геометрия эскиза в мм — единственный источник размеров, с тегом происхождения каждого числа |
| `build_cell_cad.py` | Сборка модели в FreeCAD → экспорт STEP + STL |
| `render_cell_cad.py` | Headless-рендер: размерный чертёж + изометрия |
| `out/cell_sideview.step` | **Настоящая CAD-модель** (STEP, формат из `software.md`) |
| `out/cell_sideview.stl` | Меш той же модели |
| `out/cell_sideview_dims.png` | Размерный чертёж (2 вида сбоку) — на слайд защиты |
| `out/cell_sideview_iso.png` | Изометрия экспортированной модели (проверка, что STEP тесселируется) |

## Как воспроизвести (одна команда на этап)

```bash
freecadcmd docs/defense/cad/build_cell_cad.py     # → out/*.step, *.stl
python3   docs/defense/cad/render_cell_cad.py      # → out/*.png
```

Инструмент — **FreeCAD 0.19** (разрешён `software.md`, раздел CAD). Рендер —
matplotlib + trimesh (headless, без GL). Детерминированно: одни и те же числа из
`geom.py` идут и в STEP, и в чертёж, поэтому виды перекрёстно сверяют друг друга.

## Происхождение размеров (честно)

- **Сплошная геометрия — из симуляции.** Лента (высота 0,40 м — `calc_vs_sim.md`;
  ширина 0,50 м — SDF), склиз (плита `1.4×0.605×0.02` под **34,2°**, mu=0,2 —
  `cell_diverter.sdf`, модель `chute_c`), парковка лопастей — всё измерено из
  рабочего мира Gazebo, а не выдумано. Съезд «<10 см» — это **шаг 60 мм** с
  кромки ленты на склиз (SDF: «item steps 6 cm off the belt edge onto the chute
  instead of dropping 40»), заменяющий свободное падение 0,40 м → 2,80 м/с
  (`physics_oneslide.md` строка 5, `calc_vs_sim.md` якорь 4). Угол склиза
  согласован с требованием `chute_angle.md` (`β > arctan μ`, проект 35–40°;
  34,2° из sim — на нижней кромке диапазона).
- **Reject-лоток (фиолетовый) — проектное дополнение H4, которого в текущем SDF
  НЕТ.** Мелкий лоток у схода ленты: рутинная аномалия (низкая уверенность /
  не B,C,D) уходит в reject, а аппаратный E-stop остаётся только для настоящей
  аварии (вердикт совета `council_physics.md` §слепые пятна п.3, `qa_prep.md`).

## Ограничения

- Это **эскиз**, а не производственный чертёж: без допусков, материалов
  креплений, приводов и норм безопасности. STEP несёт геометрию, не спецификацию
  изделия.
- Размеры reject-лотка (400×500×150 мм, −150 мм от ленты) — прикидочные под
  габарит худшего товара, не оптимизированные. Точная привязка к сходу ленты и
  объём — при детальном проектировании.
- Модель — жёсткие примитивы (боксы); скругления, крепёж, рама не показаны.
