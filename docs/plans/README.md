# Планы разработки

В этой папке сохранены недельные планы и фактические итоги работы команды:

- `PLAN-7DAYS.md` — первая неделя и создание сквозного прототипа;
- `PLAN-WEEK2.md` — работа с несколькими товарами и развитие восприятия;
- `PLAN-WEEK3.md` — потоковая обработка и устойчивость;
- `PLAN-WEEK4.md` — стабилизация исполнительной части и безопасности;
- `PLAN-WEEK5.md` — финальные проверки, отчёт, видео и комплект сдачи.

Главный стратегический план проекта остаётся в корневом [`PLAN.md`](../../PLAN.md).
Недельные файлы сохранены как история принятых решений и выполненных этапов.
